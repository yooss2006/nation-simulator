# 구현 태스크 및 순서
완성형 통합 공개를 목표로 하되 각 단계별 내부 실행 빌드 생성. 체크박스는 미구현 상태.

## Phase 0 — 저장소/품질 기준
- [ ] pnpm workspace, Vite 앱, Fastify API, TS 공유 설정
- [ ] Vitest/Playwright/ESLint 또는 Biome/CI
- [ ] 계약 버전, 시드 PRNG, 상태 해시, 테스트 픽스처

## Phase 1 — 세계·국가 모델
- [ ] 난이도별 세계 생성과 초기 1,000명 인구 생성
- [ ] 토지·자원·산업·주변국 생성 및 검증
- [ ] 공통 엔티티 저장·불러오기와 버전 마이그레이션

## Phase 2 — 경제 코어
- [ ] 계정·분개·재고 장부
- [ ] 가구 노동·소득·소비·저축
- [ ] 기업 창업·채용·생산·가격·투자·파산
- [ ] 노동·상품 시장 정산, GDP/물가/고용 집계

## Phase 3 — 정부·금융·정치
- [ ] 조세·예산·국채·공공조달
- [ ] 은행 예금·대출·부실 및 중앙은행 통화정책
- [ ] 법률 권한·의회 표결·정당 동태
- [ ] 대통령 결선투표·총선·생트라고식·유연형 명부
- [ ] 대통령직 상실 시 종료

## Phase 4 — 세계·인구·외교
- [ ] 출생·사망·이민·해외 이주·주거 수요
- [ ] 주요 주변국 모델·나머지 세계 거시 집계
- [ ] 수출입·환율·자본흐름·외교협정·외부 충격
- [ ] 공공건설·민간건설·인프라 생산성 연결

## Phase 5 — UX·그래픽·저장
- [ ] PixiJS 아이소메트릭 타일·건물·카메라·선택
- [ ] 정책/경제/국민/외교/의회 화면과 월간 보고서
- [ ] IndexedDB 로컬 저장, Supabase Auth
- [ ] API 저장 슬롯, 객체 스냅샷, 충돌 해결 UI

## Phase 6 — 통합 및 출시 기준
- [ ] 12개월 수동 플레이 및 100년 자동 플레이 회귀
- [ ] 모든 주요 정책 경로·선거·파산·이주 검증
- [ ] 대규모 인구 성능 프로파일링 및 최적화
- [ ] 세이브 마이그레이션·복구·보안·접근성 점검
- [ ] 튜토리얼·설정·에러 복구·배포 문서

## 최초 착수 스프린트
1. 모노레포/CI 생성
2. PRNG 및 고정 시드 월간 턴 인터페이스 구현
3. 국민·가구·기업·정부 최소 엔티티 생성
4. 단일 임금 지급 거래와 회계 불변식 테스트
5. 1개월 진행 → 스냅샷 저장 → 복원 → 결과 해시 비교
완료 기준: UI 없이 12턴을 결정론적으로 실행하고 모든 분개가 균형을 유지.
