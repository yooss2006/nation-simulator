# PRD
## 목표
완전 가상 현대 세계의 신생국 초대 대통령으로 시작해 현실적 인과관계에 따라 국가를 운영하는 PC 웹 싱글플레이. 승리 엔딩 없음. 대통령직 상실 시 종료.

## 확정 사항
- 정치 성향 다축 테스트 후 취임; 초기 국민 약 1,000명. 출생·사망·이민·해외 이주로 인구 변동.
- 쉬움/보통/어려움/극한은 초기 자원·산업·재정·인프라 조건만 차등; 경제 법칙 동일.
- 1턴=1개월. 플레이어가 월 진행을 명시적으로 실행.
- 대통령제·삼권분립. 대통령 4년 임기, 무제한 연임, 결선투표.
- 단원제 11석 고정. 전국 비례대표·생트라고식·유연형 명부. 국회의원 임기 4년, 초대 의회 2년 과도기, 대선과 총선 2년 간격.
- 정당 초기 생성 후 창당·분열·합당·소멸 가능.
- 국민·가구·기업·정부·은행의 실제 거래로 경제 통계 계산. 독자 통화, 독립 중앙은행, 시중은행, 국채, 변동환율(기본값).
- 공공 인프라는 정부가 추진, 민간 건설은 기업과 가구가 판단.
- 주요 주변국 상세 모델, 나머지 세계 거시 집계. 가상 세계 지형·자원·외교 관계 생성.
- 2.5D 아이소메트릭 국가 지도 + 정치·경제·사회·외교 대시보드.
- 브라우저 내 시뮬레이션, 로컬 저장과 로그인 기반 온라인 저장. 첫 공개는 핵심 시스템 전체 통합 후.

## 플레이 흐름
정치 성향 테스트 → 난이도/세계 생성 → 취임 → 국가 상태 열람 → 정책·법안·예산·건설·외교 명령 → 권한·자금 검증 → 월 진행 → 결과와 원인 보고 → 선거 및 위기 → 대통령직 상실 시 종료.

## 화면
시작/성향 검사, 세계 생성, 국가 지도, 정책 편집기, 경제/재정/금융, 국민/가구/기업 상세, 의회/정당/선거, 외교/무역, 공공사업, 월간 보고서, 저장/충돌 해결, 엔딩 기록.

## 정책 결과 표시
정책 시행 전에는 불확실한 전망과 근거를 제공하며, '실업률 +2%' 같은 확정 효과를 노출하지 않는다. 시행 후에는 개별 거래·고용·생산·이주 사건을 따라 원인을 추적한다.

## 변경 가능한 기본값
정당 창당 요건, 선호표 후보 순위 변경 문턱, 탄핵 절차, 법안 표결 요건, 세율, 산업 레시피, 은행 규제, 난이도 초기값은 가상 헌법·법률·데이터 파일에 정의한다. 초기 게임은 초대 대선에 당선된 상태로 시작한다.

## 출시 수용 조건
정책과 법률 절차 작동; 첫 12개월 플레이; 4년 대선 및 총선 정상 동작; 장기 플레이; 대통령직 상실 종료; 거래/재고/인구 장부 정합; 저장 후 재현; 다른 기기에서 클라우드 복원; 지도와 엔진 상태 일치.
