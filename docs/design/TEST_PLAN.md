# 테스트 전략
## 단위 테스트
화폐 최소 단위, 복식부기, 재고 흐름, 세금 과표, 생트라고식 의석 배분, 유연형 명부 후보 순위, 결선투표, 인구 변동, 명령 권한 검증.

## 통합 테스트
임금 지급→소득→소비→기업 매출→세수; 법인세 변경→법률 처리→시행→기업 장부; 공공사업 발주→조달→공사→시설 가동; 해외 공급 충격→수입가→국내 비용→물가; 은행 대출→투자→상환 또는 부실; 총선→의회 구성→법안 표결.

## 불변식
- 모든 통화별 분개 차변 합과 대변 합 일치.
- 재고·생산·소비·폐기·무역 물량 일치.
- 인구 총계와 인구 사건 일치.
- 동일 시드·상태·명령·엔진 버전에서 동일 해시.
- 정상 총선 의석 배분 총합 11; 공석은 별도 추적.
- 게임 종료는 대통령직 상실 상태에서만 발생.

## 장기 테스트
1, 10, 50, 100년 자동 진행. 인구 감소·급증, 초인플레이션, 은행 부실, 무역 중단, 정당 분열, 장기 집권, 법안 교착 시나리오. 숫자 폭주·음수 재고·고아 참조·회계 불일치 감지. 결과의 현실적 타당성은 외부 통계와 비교해 별도로 교정하며 정확한 현실 예측을 보장하지 않음.

## 저장·보안 테스트
오프라인 저장, 재연결, revision 충돌, 중복 업로드, 손상 스냅샷, 엔진 버전 불일치, 타인 저장 접근 거부, 데이터 복원, 계정 삭제.

## 성능 게이트
초기 1,000명에서 UX 반응성을 측정하고 1만/10만/100만 명 단계별 처리시간·메모리 프로파일을 수집. 성능 목표 수치는 대표 기기 벤치마크 이후 확정하며 정확도 손실 없이 최적화.
