## 다음 구현 순서

1. 경제 모델 확장: 가계 소비 바스켓, 다품목 생산 레시피, 기업 창업/투자, 은행 신용창조와 부실 정산
2. 정치·법률 완성: 개별 후보, 유연형 명부, 정당 동태, 사법부와 탄핵
3. 인구·토지·세계: 이민과 주거 시장, 민간 건설, 상세 주변국과 수출입/자본 흐름
4. 저장 운영: 실제 클라우드 연결, 충돌·복구·타기기 테스트, 오프라인 큐, 마이그레이션
5. 기획 출시 게이트: 12개월 수동 QA, 100년 회귀, 대규모 성능 측정, 보안/접근성/튜토리얼
